# Подключение модулей к STM32F407VE (STM32_F4VE_V2.0)

Документ относится к плате `STM32F407VET6 STM32_F4VE_V2.0` и проекту
`sdk/gstr-bios`. Основная конфигурация проекта находится в
`sdk/gstr-bios/gstr-bios.ioc`.

Все GPIO микроконтроллера работают с логическими уровнями 3,3 В. Земли платы
и всех внешних модулей должны быть соединены.

> Названия `PA2`, `PB10`, `PE11` и подобные ниже соответствуют маркировке GPIO
> на выводных разъёмах платы. Номер физического контакта разъёма зависит от
> исполнения платы, поэтому при подключении нужно ориентироваться на
> обозначение GPIO на шелкографии, а не на порядковый номер контакта.

## Питание

Плату можно питать штатным способом через её USB-разъём либо через контакт
`5V`, если источник имеет стабилизированные 5 В и правильную полярность.
Нельзя одновременно соединять несколько источников 5 В, если не проверена
схема их развязки.

- Сигнальные входы STM32 нельзя подключать к логике 5 В без проверки
  5V-tolerance конкретного вывода.
- Питание `3V3` платы предназначено для маломощной периферии.
- Для дисплея и WS2812 обязательна общая земля с платой.

## Дисплей ILI9341 по SPI

Дисплей остаётся на `SPI2`; параллельный TFT/FSMC-разъём платы в этой
конфигурации не используется.

| ILI9341 | STM32_F4VE_V2.0 |
|---|---|
| `SCK`, `CLK` | `PB10` |
| `MOSI`, `SDI`, `SDA` | `PC3` |
| `CS` | `PB0` |
| `RESET`, `RST` | `PB1` |
| `DC`, `RS`, `A0` | `PC6` |
| `GND` | `GND` |
| `MISO`, `SDO` | не подключать |

Линия `MISO` программой не используется. Линии SPI и управления имеют уровень
3,3 В.

Питание дисплейного модуля зависит от его исполнения:

- модуль без стабилизатора и преобразователей уровней подключается к `3V3`;
- модуль с явно указанным входом `5V` может питаться от `5V`, но его логические
  входы всё равно должны принимать уровень 3,3 В;
- если тип модуля неизвестен, сначала нужно проверить его схему или маркировку.

`PB2` не используется дисплеем и остаётся исключительно линией `BOOT1`.
Перемычки режима загрузки должны оставаться в положении загрузки из
пользовательской Flash (`BOOT0 = 0`).

## Два последовательно соединённых WS2812

Подключение модуля:

| Модуль WS2812 | STM32_F4VE_V2.0 |
|---|---|
| `DIN` | `PE11` |
| `5V`, `VCC` | `5V` |
| `GND` | `GND` |
| `DOUT` | не подключать, если следующего модуля нет |

Если используются два отдельных светодиода, а не готовый двухсветодиодный
модуль, соединение должно быть последовательным:

```text
PE11 ──> DIN LED1
          DOUT LED1 ──> DIN LED2
                         DOUT LED2 ──> не подключать

5V  ──> VCC LED1 и VCC LED2
GND ──> GND LED1 и GND LED2 и GND платы
```

Рекомендуется установить резистор 220–470 Ом последовательно между `PE11` и
`DIN` первого светодиода, а рядом с модулем — конденсатор не менее 100 мкФ
между `5V` и `GND`.

WS2812 питается от 5 В, поэтому уровень 3,3 В на `PE11` формально может быть
ниже гарантированного порога входа некоторых партий WS2812. Для надёжного
устройства следует поставить преобразователь уровня с 3,3 до 5 В, например
один канал `74AHCT125` или `74HCT14`. Для короткого провода два светодиода
часто работают непосредственно от `PE11`, но это не гарантируется
спецификацией.

Для управления используются функции:

```c
WS2812_SetLed1Color(red, green, blue);
WS2812_SetLed2Color(red, green, blue);
```

Пример:

```c
WS2812_SetLed1Color(255, 0, 0);  // LED1: красный
WS2812_SetLed2Color(0, 255, 0);  // LED2: зелёный
```

Цвет второго светодиода сохраняется при изменении первого и наоборот.

## Встроенная microSD

Дополнительные провода не нужны: слот microSD уже установлен на плате.
Проект использует его в однобитном режиме SDIO:

| Сигнал SDIO | GPIO |
|---|---|
| `SDIO_D0` | `PC8` |
| `SDIO_CK` | `PC12` |
| `SDIO_CMD` | `PD2` |

Линии `D1`, `D2` и `D3`, также разведённые на плате, текущей прошивкой не
используются. Контакт Card Detect в слоте не подключён, поэтому программа
считает карту установленной и определяет её наличие при попытке
инициализации.

## Встроенный индикатор

Один из штатных светодиодов платы используется как индикатор состояния на
`PA6`. Он подключён к питанию через резистор, поэтому активен низким уровнем:
`GPIO_PIN_RESET` включает LED, а `GPIO_PIN_SET` выключает.

## Часы реального времени

RTC работает от установленного на плате кварца 32,768 кГц. Выводы кварца
`PC14/OSC32_IN` и `PC15/OSC32_OUT` уже разведены на плате, подключать к ним
внешние устройства не нужно.

Для сохранения времени при отключении основного питания в держатель `BAT`
нужно установить батарейку, соответствующую держателю и схеме платы. Батарейка
питает домен `VBAT`; без неё часы продолжают работать только пока плата
получает основное питание.

Интерфейс часов объявлен в `sdk/middleware/include/rtc/rtc_clock.h`, а
реализация находится в `sdk/middleware/rtc/rtc_clock.c`:

```c
RTC_ClockDateTime current_time;

RTC_Clock_Set(2026, 7, 28, 12, 30, 0);
RTC_Clock_Get(&current_time);
```

При первом запуске устанавливается начальное значение
`2026-01-01 00:00:00`. Последующие сбросы микроконтроллера его не
перезаписывают. После старта прошивка выводит текущую дату и время через UART:

```text
RTC: 2026-01-01 00:00:01
```

## UART для диагностического вывода

Проект выводит сообщения `printf()` через `USART1`, 115200 бод, 8 бит данных,
без чётности, один стоп-бит.

| USB–UART | STM32_F4VE_V2.0 |
|---|---|
| `RX` | `PA9` (`USART1_TX`) |
| `TX` | `PA10` (`USART1_RX`) |
| `GND` | `GND` |

Использовать нужно USB–UART с логическими уровнями 3,3 В. Контакт питания
адаптера подключать не требуется, если плата уже питается отдельно.

Можно использовать штатный четырёхконтактный разъём `ISP_COM`, который
подключён к `USART1` (`PA9/PA10`). Линии соединяются крест-накрест:
`TX` платы с `RX` адаптера, `RX` платы с `TX` адаптера.

## Внешняя клавиатура

Кнопки активны низким уровнем: один контакт каждой кнопки подключается к
указанному GPIO, второй — к `GND`. Входы имеют программную подтяжку вверх.

| Код кнопки | GPIO |
|---|---|
| `KBRD_BTN_UP` | `PE6` |
| `KBRD_BTN_DOWN` | `PB4` |
| `KBRD_BTN_LEFT` | `PB5` |
| `KBRD_BTN_RIGHT` | `PB6` |
| `KBRD_BTN_1` | `PB7` |
| `KBRD_BTN_2` | `PB8` |
| `KBRD_BTN_3` | `PB9` |
| `KBRD_BTN_4` | `PB9` |

В текущем драйвере `KBRD_BTN_3` и `KBRD_BTN_4` ошибочно назначены на один и тот
же `PB9`. Эти две кнопки нельзя различить, пока для `KBRD_BTN_4` не будет
выбран отдельный свободный GPIO и одновременно исправлены код и `.ioc`.
Остальные четыре описанные в `keyboard.h` функции кнопок пока не внесены в
таблицу `key_map`.

## Внешний I2S DAC

Если используется модуль PCM5102 или совместимый DAC:

| I2S DAC | STM32_F4VE_V2.0 |
|---|---|
| `LCK`, `LRCK`, `WS` | `PA4` |
| `BCK`, `BCLK` | `PC10` |
| `DIN`, `DATA` | `PD6` |
| `SCK`, `MCLK` | `PC7` |
| `GND` | `GND` |

Master Clock (`MCLK`) включён и выводится через `PC7`. Контакт `SCK` на модуле
PCM5102A означает системную тактовую частоту DAC (`MCLK`), а не SPI clock.
Питание DAC следует подключать согласно документации конкретного модуля.

## Отладка и прошивка

Для SWD используются:

| Отладчик | STM32 |
|---|---|
| `SWDIO` | `PA13` |
| `SWCLK` | `PA14` |
| `NRST` | `RST` / `NRST` |
| `GND` | `GND` |
| `VTref` | `3V3` |

Отладчик не должен подавать 5 В на сигнальные линии. Для нормального запуска
перемычка `BOOT0` должна выбирать пользовательскую Flash.
