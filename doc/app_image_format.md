# Формат загружаемых приложений

BIOS ищет приложения в каталогах:

```text
/apps/<app_id>/app.bin
```

Остальные файлы каталога принадлежат приложению и BIOS их не интерпретирует.
Текущая конфигурация FatFs использует короткие имена, поэтому `app_id` должен
помещаться в формат 8.3. Имя, показываемое пользователю, хранится внутри образа
и может иметь длину до 47 байт UTF-8.

## Каталог приложений

После показа splash-экрана и успешного монтирования SD-карты BIOS сканирует
`/apps`, проверяет заголовки `app.bin` и сохраняет метаданные максимум 32
приложений в RAM. Отдельного манифеста на карте нет. Повреждённые и
неподдерживаемые образы пропускаются, отсутствие каталога `/apps` считается
пустым списком.

Каталог сортируется по имени приложения, а при совпадении имён — по `app_id`.
Ручная сортировка не предусмотрена. Сами изображения иконок в RAM не
кэшируются: меню последовательно читает из `app.bin` только видимые иконки,
используя один общий буфер 48x48 RGB565.

`app.bin` состоит из:

```text
0x0000  заголовок GAPP, 256 байт
0x0100  иконка 48x48, RGB565 little-endian, 4608 байт
0x1300  исполняемый payload для адреса 0x08020000
```

Payload начинается с обычной таблицы векторов Cortex-M4. BIOS занимает Flash
`0x08000000..0x0801ffff`, приложение — `0x08020000..0x0807ffff`.

Пример собирается командами:

```sh
cd sdk/apps/hello
make package
```

Готовый файл появится как `build/apps/hello/app.bin`. Его каталог можно целиком
скопировать в `/apps` на SD-карте.

Упаковщик `sdk/tools/gapp_pack.py` принимает готовый payload и сырую иконку
размером 4608 байт. Если `--icon` не задан, он создаёт одноцветную иконку.

## Установка с экраном прогресса

Для установки из интерфейса BIOS следует вызывать UI-обёртку:

```c
#include "app_loading_screen.h"

AppEngineStatus status = AppLoadingScreen_Install("hello");
if (status == APP_ENGINE_OK) {
    AppEngine_LaunchInstalled();
}
```

Она отображает реальный прогресс проверки файла, стирания секторов, записи и
финальной проверки Flash. Низкоуровневый `AppEngine_Install()` остаётся
доступен для установки без графического интерфейса.
