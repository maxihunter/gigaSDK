# GIMA v1 — потоковый IMA ADPCM

`ima_adpcm.c` реализует стандартный алгоритм IMA ADPCM и не зависит от файловой
системы или аудиодрайвера. Для хранения потоков gigaSDK использует небольшой
little-endian контейнер `GIMA`.

## Заголовок

| Смещение | Размер | Поле |
|---:|---:|---|
| 0 | 4 | ASCII `GIMA` |
| 4 | 1 | версия, сейчас `1` |
| 5 | 1 | каналов: `1` или `2` |
| 6 | 2 | размер заголовка: `32` |
| 8 | 4 | частота дискретизации, Гц |
| 12 | 4 | количество аудиокадров |
| 16 | 2 | начальный predictor левого/mono канала |
| 18 | 1 | начальный step index левого/mono канала |
| 19 | 1 | резерв |
| 20 | 2 | начальный predictor правого канала |
| 22 | 1 | начальный step index правого канала |
| 23 | 1 | резерв |
| 24 | 4 | размер ADPCM-данных в байтах |
| 28 | 4 | резерв |

Начальные predictor-значения являются первым аудиокадром и не повторяются в
ADPCM-данных. Последующие 4-битные коды упакованы сначала в младшую, затем в
старшую половину байта. Для stereo порядок кодов: `L1, R1, L2, R2, ...`; для
mono: `M1, M2, ...`.

Файлы создаются инструментом:

```sh
sdk/tools/audio-to-adpcm.py input.flac music.gima
sdk/tools/audio-to-adpcm.py --mono effect.wav effect.gima
```

Для воспроизведения с SD используются `Audio_PlayImaAdpcmFile()`, а для
несжатого raw PCM остаётся `Audio_PlayPcmFile()`.
